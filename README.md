# מיקרו: פלטפורמה לתכנון מיקרו חתונה

מקום אחד לבני הזוג: **אורחים**, **החלטות**, **תאריך לפי הלוח העברי**, תקציב, ספקים, משימות ולו״ז ליום החתונה. ממשק בעברית, RTL, מותאם לטלפון.

## מה יש

| אזור | מה עושים בו |
|---|---|
| **אורחים** | משקי בית עם רשימות א/ב/ג מול תקרת מקומות ("קו חיתוך"), גלי הזמנות כשמישהו מסרב, הודעת וואטסאפ מוכנה עם קישור אישי, **אישור הגעה ציבורי** (העדפת אוכל, אלרגיות), ייבוא/ייצוא CSV, הושבה (ידנית ואוטומטית) |
| **החלטות** | אפשרויות, קריטריונים עם משקל, **דירוג עיוור** של כל אחד מכם, הדגשת אי-הסכמות, סגירה עם תיעוד "מה הוחלט ולמה" (ואפשר להוסיף לתקציב), שיחה |
| **תאריך** | בדיקת תאריך לפי מנהג (אשכנז/ספרד) ואזור: שבת, חגים, צומות, העומר, שלושת השבועות, ימי זיכרון בחוק, שקיעה והדלקת נרות. חיפוש תאריכים פנויים, מועמדים, מחיר משוער |
| **תקציב** | לפי הערכה מול הצעה מול שולם, סעיפים לפי אורח, חלוקה התחלתית, מחירי ייחוס לישראל |
| **ספקים, משימות, לו״ז** | ספקים והצעות, צ׳קליסט שנגזר מתאריך החתונה (רבנות, אקו״ם, הסכם ממון ועוד), לו״ז ליום עצמו |
| **פרטיות** | ללא אנליטיקה וצד שלישי. ייצוא כל הנתונים ומחיקה |

## הרצה מקומית

דרישות: Node 22+.

```bash
npm install
npm run dev          # http://localhost:3000 , מסד נתונים מקומי מוטמע (PGlite), בלי הגדרות
npm test             # Vitest (לוגיקה + מסד נתונים בזיכרון)
npm run test:e2e     # Playwright: זרימות מלאות בדפדפן (מרים שרת dev עם מסד זמני)
npm run typecheck
npm run build
```

עם Postgres אמיתי: `DATABASE_URL=postgres://... npm run db:migrate`, ואז `npm run dev`. ראו `.env.example`.
