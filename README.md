# מיקרו חתונה

פלטפורמה לתכנון חתונה קטנה בישראל: תאריך פנוי לפי הלוח העברי והחוק, תקציב אמיתי כולל מע״מ, אורחים, ספקים, לוח זמנים ומסלול רישום (רבנות, קפריסין או יוטה).

הנתונים נשמרים **בדפדפן בלבד** (`localStorage`). אין שרת, אין חשבונות ואין אנליטיקס. אפשר לייצא ולייבא קובץ JSON כדי לעבור בין מכשירים.

## מה יש

| מסך | מה הוא עושה |
|---|---|
| סקירה | ספירה לאחור, סיכום, והתראות על מה שדורש תשומת לב |
| תאריך | לוח שנה צבוע לפי הלוח העברי: שבת, חגים, צומות, שלושת השבועות והעומר לפי המנהג שלכם, ויום הזיכרון ויום השואה לפי החוק. תאריכים זולים לפי יום ועונה |
| תקציב | מחיר לצלחת עם או בלי מע״מ, מינימום מוזמנים וצלחות ריקות, אגרת רבנות ואקו״ם אוטומטיות, חלוקה מוצעת |
| אורחים | רשימה, אישורי הגעה, העדפות אוכל, הערכת מתנות |
| ספקים | הצעות מחיר (שלוש לכל קטגוריה), שאלות ודגלים אדומים, חוזים ומקדמות |
| לוח זמנים | משימות שנבנות לאחור מהתאריך, עם מועדים קשיחים: 45 יום לתיק נישואין, 72 שעות לאקו״ם, הסכם ממון לפני החתונה |
| מסלול רישום | הרבנות, קפריסין ויוטה, רשימת מסמכים, ברור יהדות |

המידע כללי ואינו ייעוץ משפטי או הלכתי. המחירים הם טווחי שוק אינדיקטיביים.

## פיתוח

דרוש Node 22 ומעלה.

```bash
npm install
npm run dev          # http://localhost:3000
npm run typecheck && npm test && npm run build
```

הלוגיקה נמצאת ב־`src/lib` ונבדקת ב־Vitest. כל המספרים (מע״מ, אגרות, מועדים קשיחים, טווחי מחיר) ב־`src/config/benchmarks.ts`. ראו `CLAUDE.md` לכללי העבודה.
