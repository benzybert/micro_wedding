# whatsapp-pull

כלי קטן שרץ **במחשב שלכם** (לא בשרת) ומכין קובץ של האנשים שדיברתם איתם בוואטסאפ בחודשים האחרונים, כדי לייבא אותם כאורחים בפלטפורמה (אורחים ← ייבוא ← מוואטסאפ). בפלטפורמה מאשרים כן או לא לכל אחד לפני שהוא נכנס לרשימה.

## מה הכלי עושה ומה לא

- מתחבר כ"מכשיר מקושר" (כמו וואטסאפ ווב) בסריקת QR, וקורא **רק את רשימת השיחות**: שם, טלפון ומועד ההודעה האחרונה.
- **לא פותח שיחות ולא קורא הודעות.** קבוצות לא נכללות.
- שום דבר לא מועלה משם. הקובץ נשאר אצלכם עד שאתם מעלים אותו בעצמכם.
- בסיום הוא מנתק את המכשיר מהחשבון (אלא אם ביקשתם `--keep-session`), כך שלא נשאר חיבור פתוח.

## שימוש

דרישות: Node 22+ ו-Chrome/Chromium (מותקן אוטומטית עם התלויות, כ-200MB).

```bash
cd tools/whatsapp-pull
npm install
npm start -- --months 6
```

סורקים את הקוד מהטלפון: וואטסאפ ← הגדרות ← מכשירים מקושרים ← קישור מכשיר. נוצר `whatsapp-chats.json`, ומעלים אותו בפלטפורמה.

| דגל | משמעות |
|---|---|
| `--months <n>` | רק שיחות עם הודעה ב-n החודשים האחרונים (1–60, ברירת מחדל 6). בפלטפורמה אפשר לבחור חלון צר יותר, לא רחב יותר. |
| `--saved-only` | רק מספרים ששמורים באנשי הקשר בטלפון. חותך שליחים, חנויות וזרים. |
| `--out <file>` | שם קובץ הפלט |
| `--keep-session` | להישאר מקושרים אחרי הריצה (ברירת מחדל: מנתקים) |

## חשוב לדעת

- **זה לא API רשמי.** וואטסאפ לא מציעה דרך רשמית לקרוא שיחות אישיות. הכלי משתמש ב-[whatsapp-web.js](https://github.com/pedroslopez/whatsapp-web.js), ותנאי השימוש של וואטסאפ אוסרים לקוחות לא רשמיים. בקריאה בלבד ובריצה חד-פעמית הסיכון קטן, אבל קיים (הגבלת חשבון). אל תריצו בלולאה. הספרייה גם נשברת מדי פעם כשוואטסאפ מעדכנת את הממשק.
- **עוד לא נבדק מול חשבון חי.** הלוגיקה (סינון, חלון זמן, מיזוג כפילויות, והתאמה לייבוא בפלטפורמה) נבדקת במבחנים. החיבור לוואטסאפ עצמו נכתב לפי הטייפים של הספרייה ועדיין לא רץ מול טלפון אמיתי.
- **שיחות בלי מספר טלפון** (וואטסאפ משתמשת לפעמים במזהה פרטיות במקום מספר) מדולגות, והמספר מוצג בסיכום. אם יש הרבה כאלה, ספרו לנו.
- קובץ הפלט וקבצי ההתחברות (`.session`, `.wwebjs_cache`) נמצאים ב-`.gitignore`. הקובץ מכיל מספרי טלפון של אנשים אחרים: לא שולחים ולא מעלים לשום מקום חוץ מהפלטפורמה.
- שגיאת "no usable sandbox" בלינוקס כ-root: `WHATSAPP_PULL_NO_SANDBOX=1 npm start`.
